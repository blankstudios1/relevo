# Um Quiz Só Para Ti

Página de quiz de casal com tema de pinguins (ilustrações originais, inspiradas mas não copiadas de nenhuma marca), com uma surpresa no final: jantar no **Sophia — Cucina della Nonna**, sexta-feira dia 4.

Site estático (`index.html` + `style.css` + `script.js`), sem dependências.

## Ver localmente

Basta abrir `index.html` num browser, ou correr um servidor simples:

```bash
python3 -m http.server 8000
```

e visitar `http://localhost:8000`.

## Publicar com GitHub Pages

1. Vai a **Settings → Pages** neste repositório.
2. Em "Build and deployment", escolhe **Deploy from a branch**.
3. Seleciona o branch `claude/qa-page-pudgy-penguins-azinew` (ou `main`, depois de fazer merge) e a pasta `/ (root)`.
4. Guarda. Ao fim de um a dois minutos o link fica disponível em algo como `https://blankstudios1.github.io/zizi/`.
